# V8 Power Slots · Road King

The mask is available at `v8-power-road-king.html` and uses the shared 5×3 engine with 20 paylines.

- Game frame and loading art use the supplied 571×1024 images.
- The 11 supplied regular symbols have normal and bright WebP states; the bright state is used on winning positions and then restored.
- WILD, SCATTER, BONUS, win-screen art, symbol weights, paytable, and 3/5/8 BONUS free-spin awards are provisional placeholders for review.
- The RTP calculator `v8-road-king-rtp.py` yields 93% under the listed assumptions: 20 active paylines, independent weighted symbols, and no free-spin retrigger.
- Starting balance is 1000 credits and starting bet is 25 credits.

To run locally from this repository folder, start a static server (for example `python3 -m http.server 8000`) and open `/v8-power-road-king.html`.
