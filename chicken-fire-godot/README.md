# Proyecto Godot Chicken Fire (demo)

ZIP del proyecto Godot 4: unir las dos partes numeradas, extraer y abrir `project.godot`. Incluye una tragamonedas de demostracion 5x3/10 lineas, simbolos PNG originales, atlas `.tres`, y audio.

Las poses del pollo encontradas son ilustraciones estáticas distintas, no frames consecutivos de una animación. No hay runtime/atlas oficial ni matemáticas oficiales en la fuente; pagos y pesos son provisionales. Sin dinero real.
