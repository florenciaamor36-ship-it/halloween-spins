# Proyecto Godot Chicken Fire (demo)

ZIP actualizado del proyecto Godot 4: une las partes numeradas, extrae y abre `project.godot`. Incluye tragamonedas de demostración 5×3 y 10 líneas, atlas de símbolos, imágenes originales, poses del personaje y sonidos originales. La escena se ejecutó en Godot 4.3 headless sin errores de script.

Las imágenes de pollo son poses estáticas, no frames consecutivos. No incluye el runtime ni animación/atlas oficial del juego. Pesos y premios son valores provisionales y no oficiales; simulación sin dinero real.
